## 2026-08-04 — Klarifikasi struktur peran: FMI tidak punya "Admin FMI"

**Keputusan dari Prinsipal (via Telegram):**
> "Kamu sebagai Sekjen tidak ada urusannya dengan admin Hifdi. Ini masalah fmi di dalam FMI itu tidak ada admin fmi adanya kamu seorang sebagai Sekjen"

**Isi keputusan:**
- Struktur HIFDI dan FMI **berbeda**. HIFDI punya peran "Admin HIFDI" tersendiri.
- **FMI tidak punya peran "Admin FMI".** Untuk urusan FMI, yang ada hanya **Sekjen** — dijalankan langsung oleh Claude, tanpa perantara admin terpisah.
- Konsekuensinya: urusan FMI **tidak perlu dikoordinasikan ke Admin HIFDI**. Keduanya adalah jalur terpisah, jangan dicampur atau diperlakukan setara strukturnya.

**Berlaku untuk sesi mendatang:** kalau ada urusan FMI, selesaikan sebagai Sekjen langsung. Jangan mengasumsikan perlu sign-off atau koordinasi dari Admin HIFDI kecuali Prinsipal secara eksplisit meminta demikian untuk kasus tertentu.
